## Project

**Name:** DevFlow  
**Description:** DevFlow is an engineering team lifecycle intelligence platform that connects offboarding knowledge capture with onboarding knowledge delivery. It uses a multi-agent RAG pipeline to analyze departing engineers' git footprints, generate targeted exit interviews, and provide new hires with grounded answers citing institutional memory, PRs, and commit history.

### Tech Stack

- **Backend:** Python, FastAPI
- **Agent Orchestration:** LangGraph
- **LLM/Embeddings:** Claude (Anthropic API), OpenAI `text-embedding-3-small` / Voyage AI
- **Vector Database:** Chroma / Qdrant
- **Frontend:** React, Tailwind CSS
- **Data Visualization:** Recharts / D3.js
